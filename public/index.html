REST API Integration

Integrate payment verification directly into your backend with a single POST /verify call.

1. Smart Universal Endpoint (cURL)

curl -X POST https://verifier.senaycreatives.com/verify \ -H "Content-Type: application/json" \ -H "x-api-key: your_api_key_here" \ -d '{ "reference": "96f8a3d1-...", "suffix": "10001234" }'

2. Node.js (Fetch)

const res = await fetch('https://verifier.senaycreatives.com/verify', { method: 'POST', headers: { 'Content-Type': 'application/json', 'x-api-key': process.env.VERIFIER_API_KEY }, body: JSON.stringify({ reference: receiptId }) }); const data = await res.json(); console.log('Verified:', data.success, data.data.amount);

3. Dedicated Provider Endpoints

  • POST /verify-telebirr — { reference }
  • POST /verify-cbe — { reference, accountSuffix? }
  • POST /verify-dashen — { reference }
  • POST /verify-abyssinia — { reference, suffix }
  • POST /verify-cbebirr — { receiptNumber, phoneNumber }
  • POST /verify-mpesa — { reference }
